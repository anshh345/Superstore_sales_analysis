# Superstore Sales Analysis (MySQL + Tableau)

## Objective
Analyze retail sales data to find which categories, regions and
customer segments drive profit, and where the business loses money.

## Dataset
Sample Superstore dataset (Kaggle) with ~10k order line items, 2014-2017.

## Tools
MySQL Workbench, Tableau
